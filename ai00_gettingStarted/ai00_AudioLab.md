# ai00 Audio Lab: The Moves Trainer

Every AudioLab in this track is built from a small set of standard screen reader moves. This lab teaches them all against `ai00_PracticePage.html` — a page whose structure is known, so every move has a checkable right answer. Learn the moves here and every later lab is just applying them.

Open the practice page in the browser. For each move: find the command in your screen reader, run it, and record what was announced. Then compare against the expected answer.

## Move 1 — The page announcement

Just open the page and listen. **Expected:** the page title, "Trailhead Bakery - Practice Page."

## Move 6 — The table, cell by cell

Jump to the table, then walk it one cell at a time. Move down the Hours column. **Expected:** the caption ("Weekly hours") announces at the table; moving through data cells, the column header ("Hours") announces along with each value. That header-with-every-cell behavior is what a properly built table sounds like — remember it.
